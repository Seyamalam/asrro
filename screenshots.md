## Reproduce the gallery

With the development server running, execute:

```bash
./scripts/capture-screenshots.sh
```

Set `ASRRO_SCREENSHOT_EMAIL` and `ASRRO_SCREENSHOT_PASSWORD` to include authenticated dashboard captures. Credentials are read from the environment and are not stored in the repository.
